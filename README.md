# multi-encoder disfluency detection

## Overview
A deep learning-based disfluency detector for LING 230 at San José State University. We extend Liu et al.(2023) and Mohapatra et al.(2022) for experimenting with multi-encoder disfluency detection.
Trained on SEP-28k.
